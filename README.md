# Lubumbashi Connect

Annuaire vérifié, agenda, emplois et informations officielles de Lubumbashi.

## Développement

Installez [Bun](https://bun.sh/), puis lancez :

```sh
bun install
bun run dev
```

## Vérifications

```sh
bun run test
bun run lint
bun run build
```

## Technologies

- TanStack Start
- TypeScript
- React
- Tailwind CSS
